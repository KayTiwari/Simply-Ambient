# Store screenshots

Drop new phone screenshots here as `1.jpg`, `2.jpg`, ... before submitting
to Play Console.

## Play Store requirements
- **Count:** 2-8 phone screenshots (4-6 recommended).
- **Format:** JPEG or 24-bit PNG (no alpha).
- **Aspect ratio:** between 9:16 and 16:9. Portrait is fine.
- **Size:** each side 320-3840 px. The previous set was 1440x3088.
- No device frames, no added marketing text overlays that Google could
  read as misleading.
